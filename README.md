# Moved: this project is now part of Hermes Bot Kit

Bubble Mode lives on at
**[thomasbek3/hermes-bot-kit](https://github.com/thomasbek3/hermes-bot-kit)**
under [`bubble-mode/`](https://github.com/thomasbek3/hermes-bot-kit/tree/master/bubble-mode),
alongside the Computer viewer plugin. Full git history was preserved in the move.

New install (both plugins, one command):

```bash
curl -fsSL https://raw.githubusercontent.com/thomasbek3/hermes-bot-kit/master/install.sh | bash
```

Bubble Mode alone:

```bash
curl -fsSL https://raw.githubusercontent.com/thomasbek3/hermes-bot-kit/master/bubble-mode/install.sh | bash
```

The old install one-liner from this repo keeps working (this repo is archived,
not deleted), but new versions ship only from the kit.
